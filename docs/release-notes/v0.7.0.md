## Esme v0.7.0 — Ask Esme (Fase 6, parte 1)

- Nuevo: **Ask Esme** dentro del notch (`Ctrl + Alt + Espacio`, botón ⚡ o la bandeja).
- Calculadora al terminar en `=`: `1500*3+(450/2)=`.
- Conversor de monedas: `100 usd a ars=`, y dólar **blue** y **MEP**: `100 usd a blue=`.
- Timer rápido: `timer 10m` + Enter, con cuenta regresiva en la píldora.
- Preguntar, Traducir (Tab), Resumir y Corregir lo copiado con Gemini, usando tu propia API Key
  (bandeja → Configuración → IA Gemini). La key se guarda cifrada con Windows.
- El atajo no se abre encima de un juego en pantalla completa.
- Sin cambios de consumo en reposo.
