## Esme v1.0.2

Arreglo importante: **algunos antivirus (Kaspersky) marcaban a Esme como "Trojan-Spy"**, un falso
positivo. Esme no espía nada, pero usaba algunas funciones de Windows que también usan los
programas espías. Las cambiamos por alternativas más limpias:

- **API Key de Gemini**: ahora se guarda en el *Administrador de credenciales* de Windows (el lugar
  oficial para claves). **Tenés que volver a pegarla una vez** en Ajustes → Ask Esme.
- **Aviso de Wi-Fi**: usa la API moderna de Windows que solo dice "conectado a tal red".
- **Inicio con Windows**: Esme ya no reescribe su acceso directo cada vez que arranca; solo lo
  corrige si lo moviste de carpeta.
- Se quitó una lectura vieja del Registro que quedaba de las primeras versiones.
- El exe ya no necesita el redistribuible de Visual C++: funciona en cualquier Windows 10/11.

**Actualizar:** cerrá Esme (clic derecho en la bandeja → Salir), bajá el nuevo `Esme.exe` y
reemplazá el anterior. Tus ajustes se mantienen.
