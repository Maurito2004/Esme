## Esme v1.0.1

Arreglo importante: **la ciudad y el calendario ya no se borran al reiniciar la PC.**

Al prender Windows, el antivirus o un limpiador pueden tener ocupado un instante el archivo de
configuración. Esme no lo podía leer y arrancaba con los ajustes de fábrica. Ahora:

- Reintenta unos segundos hasta poder leerlo.
- Guarda de forma segura (un apagado a mitad de camino ya no deja el archivo cortado) y mantiene
  una copia de respaldo (`config.bak.json`).
- Lo mismo para tareas, agua, estante y portapapeles.
- El inicio con Windows sigue al exe aunque lo muevas de carpeta.

**Actualizar:** cerrá Esme (clic derecho en la bandeja → Salir), bajá el nuevo `Esme.exe` y
reemplazá el anterior. Tus ajustes se mantienen.
